# Bodindecha 3D — โรงเรียนบดินทรเดชา (สิงห์ สิงหเสนี) 3 มิติ

โมเดลอาคาร 3D ของโรงเรียนบดินทรเดชา (สิงห์ สิงหเสนี) บนภาพดาวเทียม เปิดได้ทันที ไม่ต้องใช้ API key

**ดูเว็บ:** https://thtpk.github.io/3D_Map/

## ฟีเจอร์
- โมเดลอาคารจากรูปทรงใน OpenStreetMap และภาพดาวเทียม ปรับรายละเอียดตามภาพถ่ายจริง
- คลิกอาคารเพื่อดูคำอธิบาย ความสูง และจำนวนชั้น
- โหมดเดินในโรงเรียน (มุมมองระดับสายตา) ใช้ปุ่มบนจอหรือ W/A/S/D
- บันทึกภาพ PNG และส่งออกโมเดลเป็น .glb ไปเปิดใน Blender / 3D Viewer

## แก้ไขข้อมูลอาคาร
ข้อมูลอาคาร (ชื่อ คำอธิบาย จำนวนชั้น ทรงหลังคา สี ช่องโล่ง ทางเดิน ฯลฯ) อยู่ใน `buildings.js` แก้ไขได้โดยตรง

## รันในเครื่อง
```bash
python -m http.server 8080
```
แล้วเปิด http://localhost:8080

## ที่มาของข้อมูล
- [CesiumJS](https://cesium.com/platform/cesiumjs/) — ตัวแสดงผล 3D
- [OpenStreetMap](https://www.openstreetmap.org/copyright) — รูปทรงอาคารและขอบเขตโรงเรียน
- Esri World Imagery — ภาพดาวเทียม
- [วิกิพีเดีย](https://th.wikipedia.org/wiki/โรงเรียนบดินทรเดชา_(สิงห์_สิงหเสนี)) — ข้อมูลอาคารบางส่วน
