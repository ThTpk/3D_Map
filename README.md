# Bangkok 3D Map — แผนที่กรุงเทพมหานคร 3 มิติ

เว็บแผนที่ 3D ของกรุงเทพฯ เลื่อน หมุน เอียง ซูมได้ อาคารแสดงตามความสูงจริง

**ดูเว็บ:** https://thtpk.github.io/3D_Map/

## ฟีเจอร์
- อาคาร 3D ไล่สีตามความสูง (เปิด/ปิดได้)
- แผนที่ 3 แบบ: สีสัน, เรียบ, ดาวเทียม
- ปุ่มบินไปสถานที่สำคัญ และช่องค้นหาสถานที่ในกรุงเทพฯ
- ปรับมุมเอียง หมุนรอบอัตโนมัติ ชื่อสถานที่ภาษาไทย ใช้บนมือถือได้
- ลิงก์เก็บมุมกล้องไว้ แชร์ให้คนอื่นเห็นภาพเดียวกันได้

## วิธีใช้
- ลากเมาส์ซ้าย = เลื่อน
- ลากเมาส์ขวา / Ctrl+ลาก = หมุนและเอียง
- ล้อเมาส์ = ซูม · มือถือใช้ 2 นิ้ว

## รันในเครื่อง
```bash
python -m http.server 8080
```
แล้วเปิด http://localhost:8080

## ที่มาของข้อมูล
- [MapLibre GL JS](https://maplibre.org/) — ตัวแสดงแผนที่
- [OpenFreeMap](https://openfreemap.org/) / [OpenStreetMap](https://www.openstreetmap.org/copyright) — ข้อมูลแผนที่และอาคาร
- [Nominatim](https://nominatim.org/) — ค้นหาสถานที่
- Esri World Imagery — ภาพดาวเทียม
